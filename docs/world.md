# Greystone — Генерація світу

## ⚖️ Принцип симетрії світу (фундаментальне правило)

Світ генерується і живе за тими самими правилами що діють у грі. Історія при worldgen — це не текстовий флейвор, а результат тієї самої симуляції яка працюватиме під час гри. NPC у згенерованій історії народжувались, працювали, успадковували і помирали за правилами village.md.

---

## Загальна концепція

Світ Greystone народжується у два кроки: спочатку **фізичний світ** (рельєф, вода, біоми, поселення), потім — **прожита історія**: світ симулюється обрану гравцем кількість років ДО того, як герой ступить у нього. Гравець приходить не в день нуль, а у світ з поколіннями, могилами, спадщиною і історіями (модель Dwarf Fortress).

---

## Екран створення світу

Перед стартом гравець налаштовує світ:

```
┌─ CREATE WORLD ─────────────────────────┐
│ Seed:      [випадковий / ввести свій]  │
│ History:   [5 ......•........ 250] рік │
│ Розмір:    (поки фіксований 100×100)   │
│                                        │
│              [ GENERATE ]              │
│                                        │
│  Рік 23: Олдрік Ешвуд помер,           │
│  ферма перейшла сину Гарету...         │
│  Рік 41: засновано село Грінфілд       │
└────────────────────────────────────────┘
```

**Вибір років історії — це вибір типу гри:**

| Роки | Світ | Досвід гравця |
|---|---|---|
| ~5 | Молодий | Перше покоління поселенців, могил немає, все щойно збудоване, земля дешева — світ для будівника |
| ~50 | Зрілий | 2–3 покоління, спадщина, вдови, старі майстри-вчителі, сімейні історії — збалансований дефолт |
| 150+ | Старий | Роди що піднялись і вимерли, руїни, покинуті села, глибокі родоводи — світ для дослідника |

Під час генерації показується **живий лог подій** — це і прогрес-бар, і перше знайомство зі світом.

**Технічне обмеження:** стеля слайдера = стільки років, скільки рушій рахує за розумний час (секунди для сіл; переглядати при додаванні фракцій/війн).

## Чотири шари генерації

### Шар 1: Фізичний світ (оверкарта 100×100)

```
1. Висотна карта — шум (value/Perlin noise, свій, ~50 рядків)
   → гори, пагорби, низини
2. Температура (широта) + вологість → біоми
3. Річки: течуть з гір вниз за градієнтом висоти,
   озера — у западинах
4. Родючість землі: низини біля води — родючі
```

Частково є: біоми, детермінований генератор секторів за seed. Додається: висоти, річки, родючість.

### Шар 2: Розселення

Поселення ставляться **за логікою, не рандомно**:

```
Село  (1 регіон)   — біля води + родюча земля
Місто (2–3 регіони) — на річках і перехрестях доріг
Замок (4 регіони)   — на висотах, контролює територію
```

Дороги з'єднують поселення — A* по оверкарті (той самий алгоритм що в грі, вартість за рельєфом: рівнина дешева, гори дорогі → дороги природно обходять гори і йдуть уздовж річок).

Профіль села від місця: біля лісу — лісоруби й мисливці, біля гір — шахтарі, біля річки — рибалки (майбутнє).

### Шар 3: Історія (серце worldgen)

Світ симулюється N років **абстрактно** (подієвий рівень, без тайлів):

```
simulateVillageYear(village):
    кожній парі         → шанс дитини (якщо є їжа і житло)
    всім жителям        → +1 рік, стадія життя перераховується
    старі               → шанс смерті від віку
                          → могила + спадщина за правилами village.md
    юнаки/юнки          → шлюби (в т.ч. МІЖ селами)
    професії            → син переймає справу / учень до майстра
    події               → неврожай, пожежа, рейд, епідемія (рідко)
    КОЖНА подія         → запис у лог історії села
```

**Результат для кожного села:** сімейні дерева на 2–3 покоління, могили за селом (з іменами і роками!), вдови й старі майстри, порожній будинок вимерлого роду (можна купити), професії з історією ("батько цього фермера був ковалем").

### Шар 4: Деталізація (вже реалізовано)

Сектор розгортається у тайли при вході гравця — детерміновано від seed + стан з шару 3 (хто живе, які будівлі, де могили). Активна зона переходить у повну предметну симуляцію (див. village.md, двошарова економіка).

## Один рушій — три застосування

**Ключове архітектурне рішення:** симуляція історії при worldgen, подієва симуляція віддалених сіл під час гри, і прискорена симуляція під час стрибків часу (сон/подорожі) — це **той самий код** (`simulateVillageYear` / його дрібніші кроки).

```
WORLDGEN:        прогнати N років для всіх сіл
ГРА, далеко:     тикати події для сіл поза активною зоною
СТРИБКИ ЧАСУ:    прискорено тикати під час сну/подорожей
```

Жодного "викидного" коду — рушій пишеться раз і живе в грі назавжди.

---

## Лог історії (Legends-шар)

З першого дня **кожна подія симуляції записується**:

```
{рік, село, тип події, учасники, деталі}
"Рік 23: Олдрік Ешвуд помер, ферма перейшла сину Гарету"
"Рік 31: Мірa з Грінфілда вийшла заміж за коваля з Довгого Броду"
"Рік 44: пожежа знищила поле родини Тетчер"
```

Дешево зараз — безцінно потім. Звідси беруться:

- Написи на могилах (ім'я, роки життя)
- Розповіді старих ("пам'ятаю ту пожежу в 44-му...")
- Відповіді NPC на "розкажи про це село"
- Історія будинку/землі яку гравець купує
- У майбутньому — режим перегляду легенд світу

## Етапи розвитку worldgen (не робити все одразу!)

**Правило: село до ідеалу → потім розширення.** Повний DF worldgen (цивілізації, 500 років війн) — окрема гра всередині гри; починати з нього = застрягнути на рік.

```
ЕТАП 1 (зараз):   симуляція села, ~50 років
                  сім'ї, народження, шлюби, смерті, спадщина,
                  професії, могили, лог подій
                  worldgen час: секунди

ЕТАП 2:           зв'язки між селами
                  шлюби між селами, торгівля, міграція

ЕТАП 3 (з фракціями): регіональна історія
                  війни, рейди орків (руїни на карті!),
                  засновані й покинуті поселення

ЕТАП 4 (далеко):  іменні легенди
                  герої, артефакти з історією, книги з авторами
```

Кожен етап залишається в грі назавжди (рушій спільний).

## Зв'язок з існуючою архітектурою

| Є зараз | Стає |
|---|---|
| Оверкарта 100×100 з біомами | + висоти, річки, родючість (шар 1) |
| ~15 сіл рандомно | Села за логікою місця + профіль від біому (шар 2) |
| `spawnVillagers()` читає ролі будівель | Читає стан з симуляції історії: сім'ї, віки, зв'язки (шар 3) |
| Детермінований генератор секторів | + розгортання стану села в тайли: могили, спадкові будинки (шар 4) |
| `WorldTime` | Продовжує історію з року N — світ не "починається", а триває |

## Порядок реалізації

```
1. Рушій simulateVillageYear(): сім'ї, віки, народження,
   шлюби, смерті, спадщина + лог подій
2. Worldgen: прогін N років для кожного села,
   spawnVillagers() читає результат
3. Екран створення світу: seed + слайдер років + живий лог
4. Могили і сліди історії в генерації сектора
5. Подієва симуляція віддалених сіл під час гри (той самий рушій)
6. Стрибки часу: сон/подорожі тикають симуляцію
7. Шар 1-2 фізичного світу: висоти, річки, логічне розселення, дороги
8. (пізніше) Етапи 2-4: міжсільські зв'язки, фракції, легенди
```
