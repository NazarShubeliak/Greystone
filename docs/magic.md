# Greystone — Система магії

## ⚖️ Принцип симетрії світу (фундаментальне правило)

**Все описане в цьому документі працює для ВСІХ істот світу, не тільки для гравця.** Гравець — частина світу, а не його центр (як у Kenshi: все що ти можеш зробити з NPC — NPC може зробити з тобою).

Це означає:
- NPC-маги мають ті самі навички шкіл, кастують ті самі закляття за тими самими правилами (стаміна, час касту, невдалі касти на низькій навичці)
- Ворожий маг може спалити тебе фаєрболом, заморозити, відкинути поривом вітру
- NPC вчаться магії у гільдіях, знаходять книги, качають школи через використання
- NPC-некромант реально піднімає трупи з тих самих свіжих корпсів
- Маг смерті серед NPC так само втрачає репутацію якщо кастує при свідках
- NPC теоретично можуть створювати власні закляття і школи — і їхні школи можна знайти/вивчити/втратити

**При реалізації будь-якої механіки з цього файлу — вона пишеться для `Actor`, не для `Player`.**

## Загальна концепція

Магія в Greystone — це глибока система знань, а не просто набір заклять. Гравець не отримує магію автоматично — її треба знайти, вивчити і практикувати.

### Ключові принципи

- **Прокачка через використання** — чим більше кастуєш школу, тим сильніше нею володієш. Вища навичка = сильніші закляття, менша вартість, швидший каст.
- **Ресурс касту** — комбінація стаміни і часу касту. Закляття втомлює тіло І займає час (в ходах). Під час касту маг вразливий.
- **Невдалі касти** — на низькій навичці закляття може провалитись або нашкодити самому магу (фаєрбол вибухає в руках).
- **Кожна школа має утиліту, не тільки бій** — магія це інструмент для життя у світі, не тільки зброя.
- **Пасивні бонуси за повне освоєння** — мотивація качати школу до майстра.

## Як вивчити магію

Кілька шляхів до магії:

1. **Гільдія магів** — офіційний шлях. Вступ, внесок, навчання базових шкіл. Легально і безпечно, але темні школи заборонені. Можуть вигнати за порушення правил.
2. **Самонавчання** — стародавні книги, свитки, артефакти з підземель. Довго і небезпечно (неправильний каст може покалічити), але доступні заборонені знання.
3. **Фракції** — вампіри навчають своєї темної магії, некроманти — некромантії, друїди — магії природи.
4. **Вчитель-відлюдник** — знайти старого мага в глушині. Навчить за послугу/квест/ціну.

Гільдія відкриває доступ до заклять, але силу гравець розвиває сам через практику.

## Базові школи (6)

Чотири стихії + Життя і Смерть. Кожна школа має чітку роль — немає "кращої".

### ВОГОНЬ — агресія і руйнування

**Філософія:** чиста атакуюча сила. Найпростіша для розуміння, найнебезпечніша для новачка — невдалі касти обпікають самого мага.

**Роль:** максимальний урон, контроль території через горіння.

| Рівень | Закляття | Опис |
|---|---|---|
| Новачок | Іскра | Слабкий снаряд, підпалює траву |
| Новачок | Тепло | Зігрітись в холод (утиліта) |
| Учень | Фаєрбол | Класичний снаряд |
| Учень | Стіна вогню | Лінія вогню на землі |
| Адепт | Вибух | Урон по площі |
| Адепт | Вогняний щит | Контактний урон нападникам |
| Майстер | Метеор | Величезний урон із затримкою |
| Майстер | **Імунітет до вогню** | Пасивно, за повне освоєння |

### ВОДА — контроль і адаптація

**Філософія:** вода не б'є — вона обмежує, гасить, змінює поле бою. Школа для тактиків.

**Роль:** контроль ворогів, дебафи, виживання.

| Рівень | Закляття | Опис |
|---|---|---|
| Новачок | Створити воду | Напитись з повітря (виживання) |
| Новачок | Струмінь | Слабкий снаряд, гасить вогонь |
| Учень | Уповільнення | Мокрий ворог повільніший |
| Учень | Призив дощу | Дощ над областю (фермерство, гасіння пожеж) |
| Адепт | Заморозка* | Ворог пропускає ходи |
| Адепт | Туман* | Зона де ніхто не бачить далі 2 тайлів |
| Майстер | **Дихання під водою** | Пасивно |
| Майстер | **Плавання без човна** | Пасивно, за повне освоєння |

\* **Важливо:** закляття пов'язані з льодом (Заморозка, Крижаний шип) вимагають додатково школи Повітря. Туман — вимагає додатково Повітря або Вогонь (вирішити на балансі). Тобто чиста Вода — це рідка вода; лід і пара — це вже комбінації.

### ЗЕМЛЯ — захист і зміна світу

**Філософія:** найповільніша але найфундаментальніша школа. Земля не атакує швидко — вона змінює саму карту.

**Роль:** захист, будівництво, контроль простору. Унікальність — єдина школа що редагує тайли карти.

| Рівень | Закляття | Опис |
|---|---|---|
| Новачок | Камінь | Кинути камінь (слабкий снаряд) |
| Новачок | Укріплення шкіри | Тимчасовий захист |
| Учень | Кам'яна стіна | Створити тайл стіни на карті |
| Учень | Трясіння | Сповільнити всіх навколо |
| Адепт | Шипи з землі | Урон по лінії |
| Адепт | Сейсмічне чуття | Бачити крізь стіни через вібрації землі (як Тоф з Аватара) |
| Адепт | Прохід крізь камінь | Тимчасово прибрати стіну |
| Майстер | Землетрус | Урон і стан по великій площі |
| Майстер | **Будування структур з каменю** | За повне освоєння |

### ПОВІТРЯ — швидкість і позиціонування

**Філософія:** школа руху. Найслабший урон але найкращий контроль позиції — своєї і ворожої.

**Роль:** мобільність, відштовхування, ухилення.

| Рівень | Закляття | Опис |
|---|---|---|
| Новачок | Порив | Відштовхнути ворога на 1 тайл |
| Новачок | Легкість | Трохи швидше рухатись |
| Учень | Ріжучий вітер | Снаряд що ігнорує броню |
| Учень | Стрибок вітру | Телепорт на 3 тайли |
| Адепт | Вихор | Відкинути всіх навколо |
| Адепт | Прискорення | Додатковий хід |
| Майстер | **Політ** | Ігнорувати пастки, воду, ближніх ворогів. За повне освоєння |

### ЖИТТЯ — відновлення і ріст

**Філософія:** магія що прискорює природні процеси. Не створює життя з нічого — підсилює те що вже живе. Лікування працює на живих, але не на нежиті.

**Роль:** хіл, бафи, взаємодія з природою і тваринами.

| Рівень | Закляття | Опис |
|---|---|---|
| Новачок | Мале зцілення | Відновити трохи HP собі |
| Новачок | Відчуття життя | Бачити живих істот поруч (навіть за стінами) |
| Учень | Зцілення ран | Лікувати конкретну частину тіла |
| Учень | Прискорити ріст | Рослина/врожай росте швидше (фермерство) |
| Адепт | Зцілення інших | Лікувати NPC і тварин |
| Адепт | Очищення | Зняти отруту, хворобу |
| Майстер | Регенерація | HP відновлюється кілька ходів |
| Майстер | Відновлення кінцівки | Зростити зламану/втрачену частину тіла |

Працює напряму з системою здоров'я по частинах тіла.

### СМЕРТЬ — розпад і межа

**Філософія:** не зло, а друга половина природного циклу. Магія розпаду, виснаження і зв'язку з тим що за межею.

**Соціальна ціна:** люди бояться магів смерті — репутація падає якщо кастувати при свідках.

**Роль:** DoT (урон з часом), ослаблення, взаємодія з мертвим.

| Рівень | Закляття | Опис |
|---|---|---|
| Новачок | Виснаження | Слабкий урон, ігнорує броню |
| Новачок | Відчуття смерті | Бачити трупи і нежить поруч |
| Учень | Гниття | DoT — урон кілька ходів поспіль |
| Учень | Ослаблення | Знизити силу/швидкість ворога |
| Адепт | Крадіжка життя | Урон ворогу, частина повертається тобі в HP |
| Адепт | Розмова з мертвим | Допитати труп — квести, інформація |
| Майстер | Пальці смерті | Величезний урон одній цілі |
| Майстер | **Стійкість до смерті** | Пасивно — шанс пережити смертельний удар |

**Дзеркальність Життя і Смерті:** Життя лікує живих — Смерть шкодить живим але не нежиті. Відчуття життя бачить живих — відчуття смерті бачить мертвих. Разом дають повну картину світу.

## Похідні школи (комбінації)

Для вивчення похідної школи потрібно знати всі її компоненти. Це не просто геймплейна умова — це має сенс у світі: залізо — це метал з землі оброблений вогнем.

| Похідна школа | Формула | Примітка |
|---|---|---|
| Залізо | Земля + Вогонь | Метал, зброя, броня |
| Лід | Вода + Повітря | Заморозка, крижані снаряди |
| Блискавка | Повітря + Вогонь | |
| Некромантія | Життя + Смерть | Підняти мертвого може тільки той хто розуміє обидві сторони межі |
| Телепортація | Повітря + Життя + Смерть | Переміщення душі через простір |
| Магія крові | Вогонь + Життя + Смерть | Власна кров як ресурс |
| Магія світла | Вогонь + Повітря + Життя | |
| Магія тіні | Земля + Вода + Смерть | |
| Магія часу | Всі 6 базових | Потрібне повне розуміння всіх сил |

Комбінації шкіл не викладають у гільдіях — тільки стародавні книги, відлюдники, фракції.

## Створення власних заклять

Система як у Morrowind але глибша — компоненти треба вивчити, а не купити.

Кожне закляття складається з трьох компонентів:

```
Форма    — як діє: снаряд, промінь, область, дотик, хвиля
Стихія   — що робить: вогонь, вода, земля, повітря, життя, смерть
Ефект    — додатковий: горіння, заморозка, відштовхування, уповільнення, контроль
```

- Компоненти вивчаються окремо в школах.
- Комбінуєш те що знаєш: Снаряд + Вогонь + Горіння = вогняна куля яка підпалює.
- Більше шкіл освоїв — більше унікальних комбінацій.
- Рідкісні компоненти — в підземеллях і стародавніх книгах.

## Створення власних шкіл магії

Вершина магічної системи — гравець може відкрити школу яку ще ніхто не знає.

**Умови:**
- Знати всі компоненти-школи на високому рівні
- Знайти теорію магії (стародавня книга або вчитель)
- Провести тривалий ритуал дослідження (ігровий час + рідкісні матеріали)

**Обмеження:**
- Не кожна комбінація дає результат — деякі несумісні
- Максимум 1–2 власні школи за життя персонажа

**Наслідки:**
- Унікальні закляття які більше ніхто не знає
- Якщо персонаж помирає не передавши знання — школа зникає з ним
- У світі можна знайти книги магів минулого які створили свої школи
- У світі мертвих можна зустріти духів великих магів і отримати їхні втрачені школи

## Магія і світи

Освоєння всіх базових стихій і проходження ліміту простої живої істоти дає можливість переміщуватись між світами (світ демонів, світ мертвих, сучасний світ тощо) без ритуалів і порталів.

- **Світ демонів** — вхід через потужну магію порталу
- **Світ мертвих** — вхід через ритуал напівсмерті (HP до 1, смерть там = справжня смерть)
- **Сучасний світ** — тільки для тих хто освоїв всі стихії; магія там працює дуже слабко

## Технічна реалізація (поточний план)

### Ресурс: стаміна + час касту

- `stamina` / `maxStamina` в базовому класі `Actor`
- Кожне закляття має `staminaCost` і `castTime` (в ходах)
- Під час касту гравець вразливий — рух скасовує каст
- `maxStamina` пізніше прив'язати до `constitution`

### Структура закляття (magic.h)

```cpp
struct Spell {
    std::string name;
    SpellSchool school;
    int damage;
    int staminaCost;
    int castTime;        // в ходах
    int range;           // в тайлах
    const char* projectileSymbol;
    SDL_Color projectileColor;
};
```

### Порядок реалізації

1. Стаміна в `Actor` ✅ (дизайн готовий)
2. `magic.h` — структури Spell і CastState
3. Перше закляття — Фаєрбол (тест)
4. Хоткей 1 → режим прицілювання → клік на ціль → каст (N ходів) → снаряд летить → урон
5. Навичка школи вогню — прокачка через використання
6. Невдалі касти на низькій навичці
7. Решта заклять школи Вогню
8. Інші школи
