# Greystone — Бойова система і зброя

## ⚖️ Принцип симетрії світу (фундаментальне правило)

**Все описане в цьому документі працює для ВСІХ істот світу, не тільки для гравця.** Гравець — частина світу, а не його центр (як у Kenshi: все що ти можеш зробити з NPC — NPC може зробити з тобою).

Це означає:
- NPC мають ті самі навички зброї (0-100) і качають їх у боях за тими самими правилами
- Ветеран-охоронець з навичкою Меч 70 реально небезпечніший за селянина з вилами — не через "рівень монстра" а через ту саму формулу
- Бандит може відрубати ТОБІ руку сокирою, оглушити булавою, пустити кровотечу мечем — ті самі ефекти зброї
- NPC знають і використовують техніки — орк-вождь з "Обезголовленням" це реальна загроза
- NPC можуть бути вчителями саме тому, що самі володіють навичками і техніками по-справжньому
- Попадання по частинах тіла, броня по зонах, промахи, штрафи від поранених рук/ніг — все двостороннє

**При реалізації будь-якої механіки з цього файлу — вона пишеться для `Actor`, не для `Player`.** (Навички переносяться з Player в Actor.)

## Загальна концепція

Бій у Greystone — покроковий, з системою здоров'я по частинах тіла і прокачкою навичок через використання. Немає класів — воїном стає той хто б'ється, так само як магом стає той хто кастує.

### Ключові принципи

- **Прокачка через використання** — кожен удар качає навичку зброї. Промах теж дає досвід (тренування є тренування), попадання більше, вбивство найбільше.
- **Рандомні попадання по тілу** — гравець не вибирає частину тіла (як Cataclysm/Kenshi). Удар летить у випадкову частину з вагами. Історії народжуються з рандому.
- **Кожен тип зброї має нішу** — немає "кращої зброї", є зброя під ситуацію і стиль.
- **Техніки як закляття** — активні прийоми що вивчаються у вчителів, вимагають рівня навички, коштують стаміну і час.
- **Єдина система навичок** — зброя і магія працюють однаково: навичка 0-100, техніки/закляття як активні вміння, вчителі/гільдії як джерело знань.

## Навички зброї

```
МЕЧ            (Sword)
ДВОРУЧНИЙ МЕЧ  (Greatsword)
СОКИРА         (Axe)
ДВОРУЧНА СОКИРА (Greataxe)
БУЛАВА         (Mace)
ДВОРУЧНА БУЛАВА (Greatmace)
КИНДЖАЛ        (Dagger)
СПИС           (Spear)
БЕЗ ЗБРОЇ      (Unarmed)
ЩИТ            (Shield)        — захисна навичка
БІЙ ДВОМА РУКАМИ (Dual Wield)  — окрема навичка поверх навички зброї
```

**Парна зброя:** тримаючи два кинджали качаються ОБИДВІ навички — Кинджал і Бій двома руками. Dual Wield це не категорія зброї а вміння координувати дві руки.

**На майбутнє:** Лук, Арбалет, Древкова зброя (посох, алебарда).

### Рівні навички (0–100)

| Рівень | Звання | Що вміє |
|---|---|---|
| 0–19 | Новачок | Мажe, б'є в піввини сили, важка зброя сповільнює |
| 20–39 | Учень | Базова компетентність, доступ до перших технік |
| 40–59 | Досвідчений | Повний урон, стабільні попадання |
| 60–79 | Ветеран | Бонусний урон, парирування, просунуті техніки |
| 80–100 | Майстер | +30% урон, крити, легендарні техніки |

### Вплив навички на бій

```
Шанс попадання:   60 + (dex атакуючого − dex захисника) × 3 + навичка / 3
                  (межі 10..95)

Множник урону:    0.5 + навичка × 0.008
                  (0.5 на рівні 0 → 1.3 на рівні 100)

Швидкість удару:  важка зброя в руках новачка коштує більше часу;
                  майстер б'є швидше базового темпу
```

### Прокачка

```
Промах:      +1 exp
Попадання:   +2 exp
Вбивство:    +5 exp

Досвід до наступного рівня: 10 + рівень × 5
(перші рівні за один бій, майстерність — за сотні боїв)
```

## Типи зброї та їх ефекти

Кожен тип зброї має унікальний бойовий ефект — це створює ніші і робить вибір зброї осмисленим.

| Зброя | Ефект | Ніша |
|---|---|---|
| **Меч** | Кровотеча (ріжуча рана → bleed) | Універсал, база |
| **Сокира** | Глибокі рани + найвищий шанс відрубати кінцівку (sever) | Проти неброньованих, калічення |
| **Булава** | Оглушення (пропуск ходу) + переломи **крізь броню** | Проти броньованих цілей |
| **Кинджал** | Швидкий (дешевший по часу) + крит у спину/по сплячому | Скритність, швидкість |
| **Спис** | Атака за 2 тайли (тримає дистанцію) | Контроль дистанції |
| **Кулаки** | Слабке оглушення, качає силу | Старт, ченці, безвихідь |
| **Щит** | Блок урону, поштовх | Захист |

**Важливо для балансу:** дробляча зброя (булави) ігнорує частину захисту броні — проти лицаря в латах меч майже безсилий, а булава ламає кістки прямо через кірасу. Гостра зброя (`sharp = true`: мечі, сокири, кинджали) може відрубувати кінцівки при добиванні.

### Дворучна vs одноручна

- Дворучна: більше урону, повільніша, не можна щит
- Одноручна: швидша, друга рука вільна (щит, факел, друга зброя)

## Попадання по тілу

Звичайна атака летить у випадкову частину тіла з вагами:

```
Тулуб:        40%
Права рука:   13%
Ліва рука:    13%
Права нога:   12%
Ліва нога:    12%
Голова:       10%
```

Наслідки (вже реалізовано в Body):
- **Голова/тулуб 0 HP** — смерть
- **Рука поранена** — штраф до сили удару (strMult)
- **Нога поранена** — штраф до швидкості (speedMult)
- **Сильні рани** — кровотеча (дренаж HP тулуба), переломи
- **Гостра зброя + 0 HP кінцівки** — шанс 40% відрубати

Броня захищає конкретну частину: шолом — голову, кіраса — тулуб, поножі — ноги, рукавиці — руки.

## Техніки (активні бойові прийоми)

Аналог заклять для воїнів. Вивчаються у вчителів, вимагають мінімального рівня навички, коштують стаміну і час.

```cpp
struct Technique {
    назва
    потрібна навичка + мінімальний рівень
    вартість стаміни
    вартість часу (дорожча за звичайний удар)
    ефект
};
```

### Приклади технік

| Техніка | Вимога | Ефект |
|---|---|---|
| Жорстокий удар | Сокира 20 | Гарантована глибока рана + кровотеча |
| Обезголовлення | Сокира 50 | ×3 шанс sever, тільки по пораненому ворогу |
| Оглушливий удар | Булава 20 | Ворог пропускає хід |
| Випад | Меч 30 | Атака з бонусом до попадання |
| Удар у спину | Кинджал 40 | ×2 урон якщо ворог тебе не бачить |
| Поштовх щитом | Щит 20 | Відкинути ворога на тайл |

### Звідки беруться техніки

1. **Вчителі-ветерани** — за гроші, квест або послугу (як маги-відлюдники)
2. **Бойові манускрипти** — в підземеллях і руїнах (як книги заклять)
3. **Фракції та ордени** — орден навчає своїх унікальних технік
4. **Спостереження** — рідкісний шанс "підгледіти" техніку у ворога який нею користується

Техніки і закляття живуть на одній панелі хоткеїв 1-9 — гібридний персонаж (паладін) має поруч і Фаєрбол і Поштовх щитом.

## Формули бою (реалізація)

```
ПОПАДАННЯ:
  chance = 60 + (attackerDex − defenderDex) × 3 + skillLevel / 3
  межі: 10..95

УРОН:
  base = weaponDamage × strMult(руки) × skillMult(навичка) + (effStr − 10) / 2
  skillMult = 0.5 + skillLevel × 0.008
  розкид: ±20%
  мінімум: 1

ЗАХИСТ:
  final = max(1, damage − defense(частина тіла))
  булави: ігнорують 50% defense

ДОСВІД:
  промах +1, попадання +2, вбивство +5
```

### Структура навичок (спільна з магією)

```cpp
enum class Skill {
    // Зброя
    SWORD, GREATSWORD, AXE, GREATAXE, MACE, GREATMACE,
    DAGGER, SPEAR, UNARMED, SHIELD, DUAL_WIELD,
    // Магія (див. magic.md)
    FIRE, WATER, EARTH, AIR, LIFE, DEATH,
    SKILL_COUNT
};

struct SkillLevel {
    int level = 0;   // 0..100
    int exp   = 0;
    void gain(int amount);
    int  expToNext() const { return 10 + level * 5; }
};

// ВАЖЛИВО (симетрія світу): навички живуть в Actor, НЕ в Player.
// Кожен бандит, охоронець і селянин має свій набір навичок.
SkillLevel skills[(int)Skill::SKILL_COUNT];  // → в Actor
```

В `Item` додається:
```cpp
Skill weaponSkill = Skill::UNARMED;  // яку навичку качає ця зброя
bool  sharp       = false;           // гостра — може відрубувати (мечі, сокири, кинджали)
```

## Порядок реалізації

1. `Skill` enum + `SkillLevel` в **Actor** (симетрія — всі істоти мають навички)
2. `weaponSkill` і `sharp` у Item та фабриках зброї
3. `combat.h` — формули попадання, урону, вибору частини тіла
4. Прокачка навички від ударів + бойовий лог з результатами
5. Ефекти типів зброї (кровотеча меча, оглушення булави, пробиття броні)
6. Техніки — структура + перші 2-3 техніки + вчитель у селі
7. Панель хоткеїв спільна з закляттями
